1. 개요

VitalGuard AI는 단일 HTML 파일로 동작하는 “인프라 독립형(Offline-first) 생존/안전 프레임워크”입니다. 핵심은 Web Bluetooth 기반 BLE 스캔으로 태그의 RSSI를 수집하고, 필터링/추정(칼만/거리추정/경량 학습) 후 존(near/mid/far/lost) 상태를 판단하여 알림·가이드·SOS 같은 기능을 제공하는 것입니다.

2. 실행 방법 / 권한 / 오프라인 원칙

  • 권장: HTTPS 환경(로컬 서버/정적 호스팅)에서 실행하면 Web Bluetooth/PWA가 가장 안정적입니다.
  • file://: 브라우저 정책에 따라 Web Bluetooth/Service Worker 일부 제한 가능.
  • 오프라인: v4.2.3은 CSP(connect-src 'none')로 의도치 않은 네트워크 호출을 차단합니다.

8. v4.2.3 보안 보강 요약

SecurityLab 코멘트의 핵심 4가지에 대해 v4.2.3에서 다음을 반영했습니다.

  1. Service Worker cache→network fallback 제거: cache-only 전략으로 변경
  2. 세션 종료 자동 삭제 옵션: autoWipeOnClose 토글 + Security.fullWipe()
  3. CSP 메타 추가: connect-src 'none' 포함(네트워크 차단)
  4. prompt() 제거: 암호 백업 패스프레이즈 입력은 SecurePrompt 모달로 대체
추가로 v4.2.3에서는 BLE 재시작 딜레이에 20~50ms 지터를 추가(결정적 타이밍 패턴 완화)했습니다. 본 앱이 BLE를 “송신”하지 않는다는 한계가 있어 코멘트의 payload padding은 적용 대상이 제한됩니다.
